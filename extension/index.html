Chrome 插件开发版安装指南

步骤 1：打开 Chrome 扩展管理页面

在地址栏输入：chrome://extensions/

步骤 2：开启开发者模式

点击右上角的 "开发者模式" 开关

步骤 3：加载扩展

点击 "加载已解压的扩展程序"，选择项目目录：

/Volumes/WD SSD/MAC/Projects/20-20-20-reminder

步骤 4：开始使用

点击工具栏中的插件图标，设置你的个性化参数，然后就可以开始使用了！

项目结构

20-20-20-reminder/
├── manifest.json      # 扩展配置文件
├── popup.html         # 弹出窗口 UI
├── css/
